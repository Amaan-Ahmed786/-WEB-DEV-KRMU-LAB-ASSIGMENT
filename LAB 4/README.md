# 📘 Simple JavaScript Quiz App

This is a **basic quiz application** built using **HTML + JavaScript**.  
It asks 5 general knowledge questions and shows the final score at the end.

---

## 🚀 Features

- 5 quiz questions  
- User answers through `prompt()`  
- Instant feedback using `alert()`  
- Score calculation  
- Final result shown at the end  

---

## 📂 Project Structure

---

## 🧠 How It Works

1. All questions are stored in a `questions[]` array.  
2. Correct answers are stored in an `answers[]` array.  
3. A loop runs through each question and shows it using `prompt()`.  
4. User input is cleaned using `trim().toLowerCase()`.  
5. If the answer matches → **Correct**  
6. If wrong → Shows the correct answer  
7. After all questions, the final score is displayed.

---

## ▶️ How to Run

1. Save the file as **index.html**  
2. Open it in any web browser  
3. The quiz will start automatically  
4. Answer all questions  
5. Your final score will appear in an alert box  

---

## 📸 What the Quiz Does

- Shows each question one by one  
- Accepts user input  
- Checks answer correctness  
- Displays total score at the end
